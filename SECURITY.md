# Security Policy

This software runs in family homes and holds authority over children's computers. If you find a
vulnerability — in the pairing flow, the code arithmetic, the session handling, anything — please
report it privately rather than in a public issue.

**Report to:** [bbednarik+digitalaid@gmail.com](mailto:bbednarik+digitalaid@gmail.com)

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a
reply from a human, though this is a spare-time project, so allow days rather than hours. Fixes ship
as ordinary releases; credit is given if you want it.

Only the latest release of the server and client is supported. There is no bounty — just gratitude.
